Waveform Capture
Trigger & raw download

Arm a level trigger: capture keeps rolling, then freezes a set number of samples after the crossing — everything already in the ring becomes pre-trigger history. Release resumes rolling capture.

idle

Raw download: 20-byte TEGC header (version, channel, flags, sample rate, count, trigger offset) + little-endian uint16 samples. Freeze first (trigger or fault) for a consistent record. voltage.tegc · current.tegc

Fault Protection
MPPT

Adaptive perturb & observe on the modulation index, fed by the power meter (needs Capture + Meter enabled). Mutually exclusive with the closed-loop feedback (same actuator); works alongside the PLL. The interval is floored at soft-start ramp + 2.1 s so each measurement is settled.

Grid / Reference PLL

Locks the output fundamental in frequency and phase to an AC reference on the feedback pin (needs Capture enabled). Steers frequency only — the waveform never jumps. Mutually exclusive with carrier dither, stepped waveform playback and the closed-loop feedback: enabling the PLL turns those off on save.

Hardware Current Limit

On-chip comparator vs internal DAC threshold, wired straight to the PWM fault input — no software in the trip path. Threshold quantizes to ~52 mV steps. Comparator-capable pins: 0, 1, 14–21, 25, 26, 38–41 (22/23 are PWM outputs on this board).

Custom Waveform

Upload a teg-wave v1 file. type=reference: one sample (-1..1) per line, resampled to the 2048-point table and played by the DDS. type=sequence: level, duration_us per line, up to 64 segments, looped (quantized to the carrier period). Select Waveform “Custom” or “Sequence” above to use it.

Firmware Update (OTA)

Starting an upload disables the inverter outputs until reboot. Upload the PlatformIO .hex build; it stages into upper flash and is structurally verified (Teensy 4.1 boot headers, board marker, density) before the Commit button becomes available. Commit rewrites the firmware and reboots — do not remove power during the ~10 s flash write. Abort invalidates the staged image and reboots into the current firmware.

MQTT / Home Assistant
